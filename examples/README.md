# 牌堆示例

`PublicDeck/` 下的 `.json` 与原版 Dice! 的牌堆包格式一致，可直接使用：

```json
{
  "牌堆名": ["卡面1", "卡面2"],
  "另一个牌堆": ["::5::权重写法", "普通卡面"]
}
```

## 启用

把 json 拷进插件的牌堆目录，然后让骰娘重载配置（或直接重启）：

```bash
cp examples/PublicDeck/*.json <bot>/data/dice/PublicDeck/
```

```
.system load
```

目录不存在时插件不会自动创建，手动 `mkdir` 即可。

同名牌堆的优先级：`data/dice/decks.yml` > `PublicDeck/*.json` > 代码内置。

## 塔罗.json

内含 7 个牌堆：

| 牌堆 | 张数 | 说明 |
| --- | --- | --- |
| `塔罗` | 78 | 全套：22 张大阿卡纳 + 56 张小阿卡纳 |
| `塔罗大阿卡纳` | 22 | 愚者 → 世界 |
| `塔罗小阿卡纳` | 56 | 权杖 / 圣杯 / 宝剑 / 星币 各 14 张 |
| `塔罗花色` | 4 | 权杖、圣杯、宝剑、星币 |
| `塔罗正逆` | 2 | 正位、逆位 |
| `塔罗牌阵` | 3 | 过去、现在、未来 |
| `塔罗单抽` | — | 演示嵌套：随机从大/小阿卡纳里抽一张 |
| `权重示例` | 5 | 演示权重：抽中愚者的概率是女祭司的 5 倍 |

用法：

```
.draw 塔罗 3            # 抽三张，同一次命令内不放回
.draw 塔罗大阿卡纳
.draw 塔罗正逆
.draw 塔罗单抽
.help 全牌堆列表        # 确认牌堆已加载
```

## 牌面语法

| 写法 | 含义 |
| --- | --- |
| `{牌堆名}` | 嵌套抽取该牌堆，**不放回**（子牌堆的剩余池全进程共用，抽空后自动补满） |
| `{%牌堆名}` | 嵌套抽取，**放回**（每次都从满牌堆抽） |
| `::张数::卡面` | 权重（前导部分会被丢弃，只取 `::张数::` 之后作为卡面） |
| `[1d6]` | 内嵌掷骰，抽到时才计算 |
| `\{` / `\}` / `\[` | 转义，输出字面量 |

> 关于「不放回」的范围：`.draw 塔罗 3` 是在**这一次命令内**不放回，牌堆本身不会被抽少——
> 每次 `.draw` 都从满牌堆重新开始。要让剩余张数跨命令保留，用
> `.deck set 占卜=塔罗` 建一个牌堆实例，之后 `.draw 占卜` 才会越抽越少，
> 抽空后 `.deck reset 占卜` 复原。
